# React Task Manager

A responsive task manager built with React, JavaScript, and CSS.
Tasks are saved in localStorage and remain available after refreshing the page.

## Features

- Add and delete tasks
- Mark tasks as completed
- Filter all or incomplete tasks
- Show the number of remaining tasks
- Save tasks in localStorage
- Responsive layout and keyboard controls

## Built with

- React
- JavaScript
- CSS
- Vite
- Vitest and React Testing Library

## Getting started

Install Node.js and npm, then run the following commands from the project folder:

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Testing

Run the automated tests:

```bash
npm test
```

To run the tests once:

```bash
npm test -- --run
```

## Production build

Build the app:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
